# 酷狗封面与验证入口修复

## 行为调整

- 修复封面刷新缓存优先级：重新进入列表优先使用已刷新的地址，不再退回歌单里的旧地址；歌曲元数据改变后仍采用最新地址。
- 安卓图片重试重新挂载图片，并跳过失败缓存；修复图片组件忽略 `onError`、缓存策略等属性变化的问题。列表请求短暂失败允许一次延迟重试，离开页面取消后续更新。
- PC 封面同样支持一次延迟恢复；请求仍合并并限制为三个并发，不借助播放来补图。
- 酷狗公共资料和榜单返回 20028 时停止内部连续重试，不继续降级请求旧播放鉴权接口。封面请求不携带账号凭证，也不自动弹验证码。
- PC「平台账号 → 酷狗」「导入与同步歌单 → 酷狗」增加独立安全验证按钮，同步和收藏目标读取失败处提供对应入口；安卓在酷狗账号歌单页及收藏目标的验证错误处提供入口。
- 验证事件过期后通过只读歌单请求获取新事件。验证完成后回读确认访问是否恢复；取消、登录失效、缺少验证事件及不支持的验证方式分别提示。验证不添加歌曲，也不自动重复收藏。
- 安卓批量同步遇到安全验证或登录失效时停止本批，保留未完成选项。

## 验证结果与边界

- PC 53 项、安卓 46 项相关回归测试通过，两端修改代码 ESLint、PC renderer/main 类型检查通过；PC 完整构建、安卓 standalone 构建和 APK 签名检查通过。
- 实际 PC 界面：酷狗台湾地区榜当前加载的 9 张封面全部成功，未通过播放触发补图；账号安全验证入口只读检查成功。
- 抽查公开榜单和歌曲资料接口均返回有效封面。酷狗旧公共榜单及旧封面接口域名存在 HTTPS 证书域名不匹配，保留原可用访问方式，不跳过 TLS 校验。账号及验证请求继续使用 HTTPS。
- 安卓模拟器剩余空间不足，本轮未安装新包；安卓原生显示效果及 issue #11 的 OPPO Find N3 设备尚待验收。
- 安卓全量 TypeScript 存在既有 deeplink、official 响应类型和 Timer 错误，本轮修改未新增类型错误。
- 平台风控由酷狗控制，不能保证彻底不触发验证。公开分享链接的限制也不保证因账号验证而解除。

预览包使用独立 `.preview` 包名，不覆盖正式版；本轮未提交、推送或发布 Release。
