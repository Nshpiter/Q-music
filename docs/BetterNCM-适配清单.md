# BetterNCM 桌面功能适配清单

本表按上游插件目录 ID 核对，同名分支、依赖库和主题各占一行，共 93 项。「可用」表示 Q-music 有对应的原生操作。核对基于 [BetterNCM 目录快照 9c0e3be](https://github.com/BetterNCM/BetterNCM-Plugins/tree/9c0e3be9bf05a49d68c008b023a26cd9a450ce2c/plugins-data)。

2026 年 11 月 24 日，使用独立 Windows 测试曲库检查了 92 个官方发布包。53 个完成初始化，21 个在启动时缺少接口、依赖或页面元素，17 个包的清单声明原生组件或宿主启动代码。另有一个 yySyncNCM 发布包下载不完整，官方目录将其标为原生插件。下表分别记录 Q-music 中的操作入口和已实测的功能。

| --- | --- |
| `PluginMarket` | 支持官方及自定义目录、依赖安装、更新、移除、自动启动和本地脚本编辑。插件升级失败会恢复旧版本。原版 osu! 搜谱、LibOpenCC 转换及 RevivedSource 注册目录已在 Windows 实测。 |
