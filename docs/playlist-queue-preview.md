## 入口与边界

歌曲收藏弹窗 → 平台收藏 → 展开目标歌单。这里只列出自己的歌单；收藏他人的歌单不会作为写入目标。服务端调用会再次核对目标，并在写入后回读，网络结果不明时只允许核对，避免反复添加。下方本地歌单仍是 Q-music 的副本。

PC 播放列表支持拖动及 Alt + 上/下调整顺序。安卓在队列中长按或点排序，再用上下按钮移动。排序只影响本次播放，不改变原歌单。

B 站独立搜索，不混入聚合歌曲搜索；BV/完整视频链接展开分 P。只解析公开 AAC 音频，不提供会员登录、付费内容或猜配歌词。平台接口仍可能受限流或内容下架影响。
