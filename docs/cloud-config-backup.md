# 配置备份与恢复（Issue #13）

沿用「设置 → 数据同步 → 云端曲库」已有的 WebDAV / S3 连接。安卓入口同样位于云端曲库中的「配置备份与恢复」，支持手机、平板和车机。原有歌曲上传、导入及歌曲加密模式保持独立。

## 使用方式

1. 在已有配置的设备保存远程连接，选择通用设置、音源及主备顺序；需要迁移账号时再勾选账号登录状态。
2. 生成或填写至少 8 位的备份密钥，保存好密钥，然后上传备份。
3. 在另一台设备配置相同服务及云端目录，填写相同密钥，查看云端备份。
4. 预览来源设备、时间、兼容设置数量、音源名称及账号平台，确认后恢复勾选项。
5. 恢复完成后重启应用。平台判定凭证失效或需要验证时，仍需重新登录或完成验证。

这是手动备份与恢复，不是定时或自动双向同步。每次上传新建快照，最多展示最近 50 份，不删除旧备份或已有本地音源。设置仅恢复白名单中的兼容项，不迁移下载目录、设备权限、窗口位置及云服务密码。

## 格式与边界

- 路径：`<云端目录>/qmusic-cloud/config/v1/<时间戳>-<随机 ID>.qmc`。
- 内容使用 AES-256-GCM、PBKDF2-SHA256（250000 次）加密，PC 和安卓格式一致；密钥不写入备份。
- 主备音源以脚本内容去重，并映射为目标设备的音源 ID。账号仅包含 QQ 音乐、网易云、酷狗自身凭证。
- 预览 5 分钟后过期，切换连接后作废；恢复一次即消费预览，重复恢复需要重新预览。
- 错误密钥、损坏格式在写入前拒绝。恢复中途失败会说明失败阶段；此前完成的部分保留，重试音源导入不会产生重复项。

# 安卓弹窗与迷你栏（Issue #12）

隐藏的 Android 原生 Modal 改为卸载，音质/队列等临时菜单进入后台或离页时清理可见状态；播放设置面板关闭后卸载，不再以延迟帧重新打开。

迷你播放器保留独立原生控制容器和稳定控件标识；播放按钮热区只在纵向扩展，避免侵入左右相邻按钮。回归脚本覆盖隐藏/再打开、后台恢复、设置面板状态与按钮回调。

Android 16 空白模拟器实测三轮设置面板关闭/保持打开 → 后台 → 前台 → 再打开，并交替验证播放队列，无旧弹窗重现。用两首本地静音 WAV 检查上一首、下一首及暂停，标题和播放状态与操作一致；暂停按钮左右边缘仅切换播放状态，不串到相邻按键。原反馈设备的厂商系统行为仍需真机验证。
