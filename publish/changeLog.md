Q-music 0.3.22

### 自定义音源优先

- 在设置中选择自定义音源后，默认播放和跨平台匹配会优先请求该音源；仅在全部失败后回退官方线路。
- 自定义音源可按声明尝试高品质、无损和 Hi-Res；手动选择平台时仍尊重本次平台优先意图。
- 播放状态记录实际 API 与缓存提供方，避免设置切换期间误读旧音源缓存或错误标记线路。

### 音质菜单

- 平台较多时改用紧凑图标网格，移除横向滚动条，并按窗口高度提供自然的纵向滚动。
- 音质面板随窗口边缘自动定位，显示“自定义源优先”、实际线路、回退状态及准确的会员提示。
- 优化键盘焦点、可访问标签与来源选中反馈，小尺寸窗口下也可完整操作。

### 多端发布

- Windows、Arch Linux 与 Android 版本统一升级至 0.3.22。

- 完善音乐平台登录账户展示、退出登录和失效状态清理。

Q-music 0.3.20

### 搜索结果排序

- 聚合搜索结合平台原生名次、跨平台共识和专辑 ID 证据，优先展示更可能的原声/正式版本。
- 未指定翻唱、混音、现场等版本词时降低变体干扰；明确输入版本词时保留对应结果的优先级。

- 重构官方线路、自定义音源、跨平台匹配与缓存的回退顺序，单条线路失败后继续尝试可用线路，不再直接跳到下一首。

- 为请求增加取消、超时和失效地址清理，连续切歌与刷新音质时更加稳定。

### 官方平台播放记录

- 使用 QQ 音乐或网易云音乐官方线路播放时，向已登录平台回报有效播放记录。
- 播放记录上报失败不会中断当前歌曲，也不会阻塞切歌。
