Q-music 0.4.10

本次正式版集中打磨 Windows 与 Android 的按钮、表单控件和弹窗动效，统一按压、悬停与键盘焦点反馈，不改动播放、同步等核心逻辑。

### PC 控件与弹窗

- 按钮悬停时轻微上浮，按下有短促的回压；禁用状态不再响应悬停，键盘操作时显示主题色焦点环。
- 勾选框选中时填充主题色底并带柔和光晕，对勾弹性出现；输入框悬停与聚焦状态更清晰，占位文字更柔和。
- 标签页改为跟随当前项滑动的指示条；滑动条悬停时加粗并显示拖动圆点，拖动中圆点放大。
- 下拉选择框支持键盘：回车或空格展开，方向键切换选项，Esc 关闭；展开和收起带缩放淡入，并修复快速重复点击时无法再次展开的问题。
- 弹窗的随机动画改为更克制的上浮、下落和侧滑淡入，关闭时快速淡出；关闭“随机动画”或动画效果后保持静态。

### Android 控件与词幕

- 图标按钮和主按钮按下时带弹性缩放反馈；勾选框对勾弹性出现并带主题底色；输入框聚焦时边框高亮。
- 状态栏歌词（词幕）的播放、暂停与进度改为直接读取原生播放器状态，切歌和状态变化时重新同步，避免歌词停在暂停状态。
- 开启系统“减少动态效果”或应用性能模式时，以上动画自动关闭。

### 安装与更新

- Windows x64、Arch Linux x64 与 Android 同步升级至 0.4.10。安卓 versionCode 40，提供 arm64-v8a、armeabi-v7a、x86、x86_64 和通用安装包，大多数手机请选择 arm64-v8a。
- 已完成 PC 构建与 36 项现有测试、安卓代码检查、类型检查与 157 条回归断言；动效在不同设备上的实际观感仍需使用中验证。

Q-music 0.4.8

本次正式版专注打磨 Windows 与 Android 的界面动效、加载状态和细节交互，不改动播放、同步等核心逻辑。

### PC 界面与动效

- 页面切换加入淡入过渡；左侧导航与设置目录改用跟随当前项滑动的高亮指示。

- 歌单广场改为自适应网格卡片，依次浮现，悬停时卡片上浮并显示播放提示，支持键盘打开。

### Android 界面与动效

- 歌单详情页上滑后顶栏标题切换为歌单名，封面尺寸与圆角和其他页面统一。
- 每日推荐、排行榜、搜索歌曲、歌单详情和歌单广场加载时显示骨架占位；每日推荐加载失败可直接重试，每日图片加载后淡入。
- 开启系统“减少动态效果”或应用性能模式时，以上动画自动关闭。

### 安装与更新

- Windows x64、Arch Linux x64 与 Android 同步升级至 0.4.8。安卓 versionCode 38，提供 arm64-v8a、armeabi-v7a、x86、x86_64 和通用安装包，大多数手机请选择 arm64-v8a。

Q-music 0.4.5

### 云端曲库

- Windows 与 Android 支持 S3 兼容存储和 WebDAV；各服务的配置独立保存，切换时不会覆盖另一服务的密钥。

- 本版提供手动上传和导入，不会在后台自动双向同步或删除云端文件；OneDrive 暂不支持。

### 发布范围

- Windows x64、Arch Linux x64 与 Android arm64/通用安装包统一发布为 0.4.5。
