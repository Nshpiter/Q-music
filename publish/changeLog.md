Q-music 0.3.18

### 搜索与来源选择

- 搜索框来源选择改为紧凑下拉菜单，可与历史搜索和平台热搜面板共存。
- 修复回车或点击热搜后搜索面板残留、过期提示覆盖和多平台切换异常。
- 补充平台来源图标与统一的加载、空状态反馈。

### 歌单、排行榜与账号

- 修复歌单、QQ 音乐“我喜欢”和排行榜内容空白或加载失败。
- 增加请求重试、响应校验及失效状态恢复。
- 优化 QQ 音乐与网易云音乐账号状态检测、登录信息展示和退出登录流程。

### 多端发布

- Windows、Arch Linux 与 Android 版本统一升级至 0.3.18。

Q-music 0.3.15

### 播放音质

- 播放详情页新增音质快捷菜单，支持标准、HQ、无损与 Hi-Res。
- 切换音质时保留播放进度和播放状态；目标音质不可用时自动降级。
- 继续优先使用平台官方可用线路，失败后无感回退到自定义接口与跨源匹配。

### 排行榜与来源

- 排行榜请求增加自动重试、异常响应校验和失效榜单恢复，减少偶发加载错误。
- 歌曲列表、搜索结果与排行榜补充各平台官方来源图标。
- Android 播放详情设置补充音质切换，并同步榜单重试与来源标识。

### 多端发布

- Windows、Arch Linux 与 Android 版本统一升级至 0.3.15。

Q-music 0.3.14

### 智能播放线路

- QQ 音乐与网易云音乐优先使用平台官方可用播放地址。
- 官方线路会按音质自动降级；不可用时无感回退到现有自定义接口和跨源匹配。
- 桌面端复用已登录的音乐账号会话，Android 端优先直连官方免费歌曲。
- 独立短时缓存避免官方临时地址与已有音源缓存互相覆盖。

### 多端发布

- Windows、Arch Linux 与 Android 版本统一升级至 0.3.14。
- 保留 Arch Linux 原生 Wayland 的轻量合成与音频可视化降载策略。

Q-music 0.3.13

### Arch Linux / Wayland 流畅度

- 原生 Wayland 自动采用轻量合成路径，关闭大面积实时毛玻璃采样。
- 音频可视化在 Wayland 下调整为 20 FPS、1 倍像素密度与 512 点 FFT。
- 减轻沉浸播放页背景模糊，保留封面主题色与氛围层次。
- 增加 GPU 合成与光栅化状态日志，方便定位 NVIDIA、Mesa 或合成器回退问题。

Q-music 0.2.9

### 个性化推荐

- 支持在 QQ 音乐与网易云音乐之间选择每日推荐来源。
- QQ 音乐接入私人雷达，并支持通过腾讯官方授权获取真正的“每日30首”。

- 网易云音乐支持读取账号歌单及完整歌单详情。

### 首页与体验

- 首页改为更接近 QQ 音乐的信息卡片布局，补充今日推荐与歌单宝藏库。
- 修复推荐详情歌曲数量不完整、账号登录回调及歌单详情空白等问题。

Q-music 0.2.5

- 增加配对状态、设备数量和异常反馈。

Q-music 0.2.2

### Linux Wayland 图形渲染

- 原生 Wayland 默认使用 ANGLE/EGL，避免 NVIDIA 驱动下 desktop GL 初始化失败后回退到软件渲染。
- X11/XWayland 继续使用 desktop GL，不改变现有兼容路径。
- 尊重用户显式传入的 `--use-gl` 与 `--use-angle` 参数，并在日志中输出最终图形后端。
- 修正 `disable-gpu-sandbox` 启动参数格式。

Q-music 0.2.0

本版本基于 LX Music Desktop 2.12.2 二次修改。

### 界面全面焕新（液态玻璃）

- 外壳与内容面板改为低透明度中性白毛玻璃，自定义背景图能真正透过面板显示。
- 新增「背景与毛玻璃」设置：一键选择全局背景图，面板透明 / 模糊程度滑块实时调整并记忆。
- 主题颜色选择器升级为迷你玻璃预览卡，选中态带主题色柔光圈。
- 左侧导航去掉选中竖线，改为主色实心图标胶囊；设置侧栏图标未选中改为中性灰。
- 右键 / 下拉菜单统一为主题感知磨砂浮层，主色柔和 hover 胶囊。
- SQ / Hi-Res 等徽标胶囊化。

### 播放栏重做

- 播放簇（上一首 / 播放 / 下一首）真正居中，图标重绘为实心圆角风格。
- 播放键改为主题色渐变 + 发光；进度条改为主题色，新增 hover / 拖拽圆点。
- 右侧工具图标按「面板开关 | 播放设置 | 动作」分组加细分隔线；当前播放时间加重显示。

### 列表与动画

- 列表行优化：正在播放行主色高亮 + 均衡跳动条，hover 磨砂圆角底，文字加可读性微衬底。
- 打开歌曲评论改用 FLIP 连续滑动动画，卡顿吸收在静止阶段，全程丝滑。

### 更新设置

- 新增「启动时自动检查更新」开关；修复「软件更新」设置节不可见的问题。
