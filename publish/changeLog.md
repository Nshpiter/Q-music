Q-music 0.2.4

### 首页与搜索

- 首页改为更简洁的推荐卡片布局，移除多余的来源标签与占位图标。
- 聚合搜索按 **歌名 + 歌手** 合并重复结果，每首歌只显示一个词条。
- 结果中可直接切换真实音乐源，不再显示容易混淆的来源别称。
- 修复在歌单与歌曲页面之间切换后内容区可能空白的问题。

### 推荐与同步

- 优化每日推荐入口与卡片信息层级。
- 补充多端同步的登录入口与状态反馈。

### 更新体验

- 修复更新接口失败时误显示“已是最新版本”和 `0.0.0` 的问题。
- 更新内容支持 Markdown 标题、列表、强调、链接、引用与代码块。
- 更新日志中的外部链接使用系统浏览器安全打开。

Q-music 0.2.2

### Linux Wayland 图形渲染

- 原生 Wayland 默认使用 ANGLE/EGL，避免 NVIDIA 驱动下 desktop GL 初始化失败后回退到软件渲染。
- X11/XWayland 继续使用 desktop GL，不改变现有兼容路径。
- 尊重用户显式传入的 `--use-gl` 与 `--use-angle` 参数，并在日志中输出最终图形后端。
- 修正 `disable-gpu-sandbox` 启动参数格式。

Q-music 0.2.0

本版本基于 LX Music Desktop 2.12.2 二次修改。

### 界面全面焕新（液态玻璃）

- 外壳与内容面板改为低透明度中性白毛玻璃，自定义背景图能真正透过面板显示。
- 新增「背景与毛玻璃」设置：一键选择全局背景图，面板透明 / 模糊程度滑块实时调整并记忆。
- 主题颜色选择器升级为迷你玻璃预览卡，选中态带主题色柔光圈。
- 左侧导航去掉选中竖线，改为主色实心图标胶囊；设置侧栏图标未选中改为中性灰。
- 右键 / 下拉菜单统一为主题感知磨砂浮层，主色柔和 hover 胶囊。
- SQ / Hi-Res 等徽标胶囊化。

### 播放栏重做

- 播放簇（上一首 / 播放 / 下一首）真正居中，图标重绘为实心圆角风格。
- 播放键改为主题色渐变 + 发光；进度条改为主题色，新增 hover / 拖拽圆点。
- 右侧工具图标按「面板开关 | 播放设置 | 动作」分组加细分隔线；当前播放时间加重显示。

### 列表与动画

- 列表行优化：正在播放行主色高亮 + 均衡跳动条，hover 磨砂圆角底，文字加可读性微衬底。
- 打开歌曲评论改用 FLIP 连续滑动动画，卡顿吸收在静止阶段，全程丝滑。

### 更新设置

- 新增「启动时自动检查更新」开关；修复「软件更新」设置节不可见的问题。
